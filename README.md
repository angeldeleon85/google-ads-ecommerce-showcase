# Google Ads Ecommerce Showcase

Professional Google Ads ecommerce measurement project covering feed strategy, dynamic remarketing, and Performance Max readiness.

## Capabilities Covered

- Google Ads conversion tracking planning
- Enhanced conversions implementation planning
- Retail dynamic remarketing event parameters
- GTM-compatible data layer implementation patterns
- Product feed alignment with Merchant Center IDs
- Performance Max product segmentation strategy
- Shopping campaign readiness and custom-label planning

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
